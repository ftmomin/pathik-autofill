    Developer Guide

    Storing Guest Data

    Call window.formAutofill from any client component on an allowed site. The function returns a Promise that resolves on success or rejects with a descriptive error. 

    // From your hotel management system / PMS client component
try {
  await window.formAutofill({
    data: {
      first_name: "Kajal",
      last_name:  "Gangani",
      email:      "guest@example.com",
      mobile_no:  "9820355183",
      phone_no:   "9820355183",
      dob:        "05-05-1993",
      address:    "123 Main St",
      locality:   "Thane",
      city:       "Thane",
      district:   "Thane",
      zip_code:   "400604",
      country:    "india",
      state:      "maharashtra",
      coming_from: "Thane",
      going_to:    "Thane",
      doc_type:   "aadhar card",
      doc_no:     "270715127847",
      room_no:    "306",
      checkin_date:  "03-06-2023",
      checkin_time:  "14:00",
      checkout_date: "04-06-2023",
      checkout_time: "12:00",
      child:  0,
      adult:  2,
      vehicle_type: "Other",
      vehicle_registration_no: "",
      other_guests: [
        {
          other_full_name:       "Bhavesh Tank",
          other_mobile_number:   "9820355183",
          other_doc_type:        "aadhar card",
          other_document_number: "958952493001"
        }
      ]
    }
  });
  console.log("Saved for autofill");
} catch (err) {
  if (err.message === "data exist") {
    console.warn("Guest already saved for this check-in date");
  } else if (err.message.includes("not a valid option")) {
    console.error("Select field value not in page options:", err.message);
  }
}

    Reading Stored Entries

    Use window.formAutofill.getEntries() to retrieve all currently stored guest entries from your PMS client code. Entries are returned oldest-first. 

    const { entries } = await window.formAutofill.getEntries();
// entries: array of guest objects in insertion order (oldest first)
console.log(entries.length); // 0–5
    OutcomeResult
    Success Promise resolves { entries: [...] }
    Timeout after 5 s throws Error("Form Autofill: getEntries timed out")

    Extension Detection

    Check whether the extension is installed before calling the API. Two read-only properties are set on the function object at page load. 

    if (window.formAutofill?.isInstalled) {
  console.log("Extension active, version:", window.formAutofill.version);
} else {
  // prompt the user to install the extension

    Return Values — window.formAutofill()

    Outcome Result
    Entry saved { success: true }
    Same name + check-in date already stored throws Error("data exist")
    Select field value not in page options throws Error('"value" is not a valid option for "field"')
    Extension not responding (10 s) throws Error("Form Autofill: request timed out")

    Storage Behaviour

    Up to 5 entries are stored locally in the browser via chrome.storage.local. When a sixth entry is added the oldest one is overwritten (circular buffer). Duplicate detection compares first_name + last_name + checkin_date (case-insensitive).

    Lazy-Loaded Dropdowns

    The fields country, state, and doc_type use Bootstrap Select dropdowns whose options load dynamically. The extension handles these automatically:

    1. country is filled first — the dropdown is opened, the value is typed into the live-search box, and the best matching option is clicked.
    2. A 1.5 s delay follows to allow the page's AJAX cascade to reload the state list.
    3. state is filled next using the same search-and-click approach.
    4. doc_type is filled last.

    Option matching prefers an exact text match, then a starts-with match, then the first visible item. Hidden items (filtered out by live-search) are skipped automatically.

    Help

    How to use Form Autofill

    1. Store guest data

      From your hotel management system, call window.formAutofill({ data: … }) to save a guest record. Up to 5 records are stored locally in your browser.

    2. Navigate to pathik.guru

      Open the guest registration form on pathik.guru.

    3. Right-click on the page

      Right-click anywhere on the form and select "Autofill Form" from the context menu.

    4. Select a guest

      A panel appears showing your saved guest entries (newest first). Click a guest to fill all matching form fields automatically.

    Troubleshooting

    "Autofill Form" doesn't appear in the right-click menu
    Make sure the current domain is listed in Settings → Allowed Websites.
    Form fields aren't being filled
    The extension matches fields by their name attribute. If pathik.guru updates their form structure the selectors may need adjusting.
    I get "data exist" error
    A guest with the same name and check-in date is already stored. Entries are overwritten in order once 5 are stored — the oldest will be replaced next.
    The extension is not working on my site
    Add your domain in Settings → Allowed Websites and reload the page.
